# 台帳（s/*.md）への改善要望

- 書いた日: 2026-09-12
- 書いた人: Claude Code（合同会社StartWith / startwith.org のデザイン改善の作業中）
- きっかけ: startwith.org のデザインを1日1課で直す作業で、この台帳を参考に使おうとしたときに足りなかったもの

台帳は403件あり、**色・文字サイズ・セクションの上下余白・カラムの比**はよく揃っている。
そのまま変数にできる形なのも使いやすい。以下は「使ってみて足りなかった」ぶんだけを挙げる。

---

## 1. 見出しの前後の余白が無い（いちばん困った）

`s/*.md` には次が入っている。

| 入っているもの | 例（aksball.md） |
|---|---|
| 文字サイズと行間の段 | 大見出し187px / 見出し62px / 本文18px・行間1.8 |
| セクションの上下余白 | 56px（スマホ32px） |
| 並びの間隔 | 37px |
| 版面 | 936px |

**入っていないもの：見出しの上の余白と、下の余白。**

デザインの4原則のうち「近接」は、まとまりの中の余白と、まとまりどうしの余白の**比**で決まる。
セクションの上下余白（56px）だけ分かっても、その中で

```
ラベル（SERVICE）
　↕ ここが何px
見出し（サービス）
　↕ ここが何px
本文
```

が分からないと、見出しのまとまりを真似られない。

実際に困った例：startwith.org は「小さいラベル → 見出し → 本文」の型を全ページで使っている。
この3つの間隔の比が、社内で 1.25倍 / 1.43倍 / 2.0倍 / 2.67倍 とバラバラだった。
台帳で参考サイトの比を見ようとしたが、どのファイルにも無かったので、
6サイトを自前で測り直すことになった（測った結果は 1.16〜30.57倍。定数は無かった）。

**要望：`## 文字` の表に2列足す。**

| 役割 | サイズ | 行間 | 上の余白 | 下の余白 |
|---|---|---|---|---|
| 見出し | 62px | 1.4 | 14px | 28px |
| 小見出し | 46px | 1.4 | 24px | 16px |

測り方は「その要素の上端 − ひとつ上の文字要素の下端」「ひとつ下の文字要素の上端 − その要素の下端」で取れる。
margin ではなく**実際に描かれた間隔**で取ってほしい（margin の相殺や flex の gap があるため）。

---

## 2. 「ラベル付き見出し」を型として記録してほしい

日本のBtoBサイトは、ほぼ全部が次の型になっている。

```
SERVICE          ← 小さい英字ラベル（12〜15px）
サービス          ← 見出し（32〜62px）
─────            ← 罫線が入ることもある
本文…
```

台帳の `## 部品` や `## ページの組み立て` に、この型があるかどうかと、
**ラベルの文字サイズ・字間・見出しとの間隔**が入ると、そのまま組める。

いま台帳から分かるのは「文字サイズの段」だけなので、12px がラベルなのか注釈なのかが読み取れない。

---

## 3. 入れ子の書き方も残してほしい

6サイト測って分かったこと：**ラベルと見出しを兄弟に置くか、箱で包むかがサイトによって違う。**

- startwith.org：`<p class="label">` と `<h2>` が兄弟
- さくらコピー・JQ・NUE：ラベルと見出しを `<div>` で包んでいる

包んであると、外から見たときに「ラベルと見出しは1つのまとまり」だと分かる。
台帳の `## すぐ使う骨格` に、見出しまわりのHTMLが1ブロックあると助かる。

```html
<div class="c-head">
  <p class="c-head__en">SERVICE</p>
  <h2 class="c-head__ja">サービス</h2>
</div>
```

---

## 4. `data.json` に業種のほかに「判型」があると選びやすい

いまの `data.json` は slug / name / url / industry / tags / accent / palette。
ここに **版面幅・本文サイズ・セクション上下余白** の3つだけでも入ると、
「自社（版面1162px・本文16px）に近いサイト」を403件から機械で絞れる。

いまは industry の文字列で絞るしかなく、
「コンサルティング」で100件出たあと、1件ずつ `s/*.md` を開いて判型を確かめることになる。

---

## 5. 測れなかったサイトに印がほしい

ジンズホールディングス（jinsholdings.com）はボット対策で 403 を返し、自動で測れなかった。
台帳側にも `"blocked": true` のような印があると、測りに行く前に分かる。

## 参考：今日この台帳を使った流れ

1. 学課 A01「近接」を学ぶ
2. 社長が指定した参考サイト4社（さくらコピー・ヒューマンアイズ・ウェルモ・ジンズ）を深める
3. **この台帳から、自社に近いジャンルを探す** ← ここで industry で絞り、JQ・NUE・ランドソリューションを選んだ
4. 自社サイトを1件だけ直す

3 の「探す」までは台帳がよく効いた。**4 で使う数字（見出し前後の余白）だけが無かった。**
