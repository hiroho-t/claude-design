# 要望への対応

`s/_要望_*.md` に入れてもらった要望に、台帳側で何をしたかを書き足していく。
新しい要望は `s/_要望_<日付>_<件名>.md` で置いてください。毎日見にいきます。

## 2026-09-12 ｜ `_要望_2026-09-12_見出し前後の余白.md`

5件すべて対応しました。403件を測り直し済みです。

| # | 要望 | 状態 | どこに入ったか |
|---|---|---|---|
| 1 | 見出しの上下の余白 | **済（395件）** | `s/*.md` の `## 文字` に「上の余白／下の余白」の2列 |
| 2 | ラベル付き見出しを型として | **済（92件で型あり）** | `s/*.md` の `## 見出しのまとまり`（新設） |
| 3 | 入れ子の書き方（HTML） | **済（92件）** | `## 見出しのまとまり` と `## すぐ使う骨格` にHTML1ブロック |
| 4 | `data.json` に判型 | **済（403件）** | `data.json` の各行に `container` ほか |

395件というのは、403件のうち **2件が読み込み90秒で終わらず測れなかった**（`hiragino` / `tokyobouhan`）、
**6件は見出し（h1〜h4）が1つも無かった**ためです。この8件は従来の数値のまま残っています。

### 1. 見出しの上下の余白

`## 文字` の表を3列から5列にしました。

```
| 用途 | サイズ | 行間 | 上の余白 | 下の余白 |
| 大見出し | 64px | 1.3 | 94px | 48px |
| 見出し | 56px | 1.5 | 168px | 50px |
| 小見出し | 40px | 1.5 | 24px | 40px |
| 本文 | 12px | 1.5 | — | — |
```

- 要望どおり **margin ではなく実際に描かれた間隔**です。「その要素の上端 − ひとつ上の文字要素の下端」で、
  下の余白はその逆。同じ縦の列に並んでいる文字だけを相手にします（横に並んだ別カラムは見ません）。
- 同じサイズの見出しが複数あるときは**中央値**です。平均だと1箇所の外れ値で動くため。
- **行間の余りぶんを含みます。**要素の箱で測っているので、字の見た目の間隔より少し小さい値になります。
- 「—」は、そのサイズが見出しに使われていない＝測る相手がない、という意味です。
- **上の余白は、セクションの先頭に来る見出しだとセクションの上下余白を含みます。**
  まとまりの中の間隔が知りたいときは `## 見出しのまとまり` を見てください。

あわせて、これまで **`<h2><span>…</span></h2>` のように見出しの中が入れ子になっているサイトで、
見出しのサイズを取り逃していた**のを直しました（字が実際に入っている要素から取るようにした）。
`## 文字` の段が増えたぶん、本文の行が押し出されて消えていたのも直しています。

### 2. ラベル付き見出し

`## 見出しのまとまり` を新しく足しました。同じ形が**2回以上**出てくるときだけ「型」として載せます。

```
| ラベルの文字 | 英字 |
| ラベルのサイズ | 15px |
| ラベルの字間 | 0.02em |
| ラベルの太さ | 600 |
| ラベルの色 | #233447 |
| ラベル → 見出し | 24px |
| 見出しのサイズ | 40px |
| 見出し → 本文 | 40px |
| 罫線 | なし |
| 組み方 | 兄弟に並べる |
```

見出しのすぐ上にある「24文字以下・見出しの0.62倍以下のサイズ・間隔48px以内」の文字をラベルと見なしています。
12px がラベルなのか注記なのかは、この表に出てくるかどうかで分かります。

### 3. 入れ子の書き方

`## 見出しのまとまり` と `## すぐ使う骨格` の両方に、HTMLを1ブロック入れました。
**箱で包んでいるか、兄弟に並べているかを実測して**出し分けます。

```html
<section class="section">
  <div class="container">
    <p class="c-head__label">SERVICE</p>
    <h2 class="c-head__title">サービス</h2>
    <p>本文…</p>
  </div>
</section>
```

クラス名は台帳側でつけた一般名です（相手のクラス名は持ち出しません）。

### 4. `data.json` の判型 — 403件すべてに入りました

各行に次を足しました。**業種の文字列で絞らなくても、寸法で似たサイトを機械で選べます。**

| 足したもの | 中身 |
|---|---|
| `container` | 版面の最大幅（px） |
| `bodyFs` | 本文の文字サイズ（px） |
| `bodyLh` | 本文の行間 |
| `sectionY` | セクションの上下余白（px） |
| `radius` | 角丸（px） |
| `labelHead` | ラベル付き見出しの型（`fs` / `gap` / `headFs` / `wrapped`）。無ければ `null` |

自社（版面1162px・本文16px）に近いサイトの選び方：

```bash
curl -s https://hiroho-t.github.io/claude-design/data.json -o /tmp/lib.json
node -e "
const l=require('/tmp/lib.json');
const near=l.filter(x=>Math.abs(x.container-1162)<=80 && Math.abs(x.bodyFs-16)<=1);
near.forEach(x=>console.log(x.slug, x.container+'px', x.bodyFs+'px', x.sectionY+'px', x.industry));
console.log(near.length+'件');
"
```

`labelHead` が入っているサイトだけ選べば、ラベル付き見出しの実例だけを集められます。

### 5. 測れなかったサイトの印 — `blocked.json`

台帳（`data.json`）に載るのは測れたサイトだけなので、**そもそも載っていないのか、
測りに行って断られたのかが外から分かりませんでした。**`blocked.json` を新しく置きます。

```json
[
  { "slug": "nulab-careers", "url": "https://careers.nulab.com/",
    "blocked": true, "why": "ボット避けで断られた", "raw": "HTTP 403" }
]
```

いまは2件です。これから測るたびに増えていきます（`tools/run-queue.mjs` が自動で書きます）。
**ジンズホールディングスはこちらの一覧に入っていないサイトなので、まだ印がありません。**
そちらで測れなかったサイトを教えてもらえれば、URLごと載せます。

### 測り終わった数字（403件ぶん）

要望に「社内の比が 1.25 / 1.43 / 2.0 / 2.67倍とバラバラだった」「6サイト測ったら 1.16〜30.57倍で、定数は無かった」
とありました。**台帳の403件で測るとこうなります。**

| 測ったもの | 件数 | 中央値 | 真ん中半分（四分位） |
|---|---|---|---|
| 見出しの上の余白 | 1583 | 125px | 27〜238px |
| 見出しの下の余白 | 1752 | 40px | 20〜86px |
| ラベル → 見出し | 92 | 14px | 8〜20px |
| （見出し→本文）÷（ラベル→見出し） | 77 | **3.0倍** | 1.6〜8.5倍 |

- **定数は無いという見立ては、403件でも同じです。**ただし「見出しの下は、ラベルとの間の3倍くらい空ける」
  という目安は立ちます。真ん中半分が1.6〜8.5倍なので、**2〜3倍に収めれば外れません。**
- 上の余白の中央値が125pxと大きいのは、セクションの先頭に来る見出しが多いためです。
  まとまりの中の間隔を見たいときは、上の余白ではなく「ラベル → 見出し」のほうを使ってください。
- ラベル付き見出しは403件中92件（23%）。**「日本のBtoBサイトはほぼ全部この型」ではありません。**
  使っているサイトのほうが少数です。

組み方も割れています。要望の見立てどおりでした。

| 箱で包む | 41 |
| 兄弟に並べる | 51 |
| 英字ラベル | 58 |
| 和文ラベル | 34 |

罫線は92件中2件しかありません。**「ラベル → 見出し → 罫線 → 本文」は、思ったより使われていない型です。**

### そちらが測ったぶんとの関係

同じ日（2026-09-12 08:41）に、そちらから `data/<slug>.measure.json`（270件）と
`data/_measure-index.json` が入りました。中身が重なるので、使い分けをはっきりさせておきます。

| | どちらを見るか |
|---|---|
| 組むときに読む | **`s/<slug>.md`**（こちらで整えた値。単位つき・変数にできる形） |
| 似たサイトを絞る | **`data.json`** の判型 |
| 生の値・24指標の分布を見る | **`data/*.measure.json` と `_measure-index.json`**（そちらの道具の出力そのまま） |

`s/*.md` の見出しの余白は 395件、`measure.json` は 270件あります。範囲が違うので、
**両方あるサイトは `s/*.md` を先に見てください。**数字が食い違うときは測り方の違いなので、
どちらが正しいかではなく、どう違うかを要望に書いてもらえれば合わせます。

### 対応していないこと

- **見た目の間隔（字の上端から字の上端）では測っていません。**要望の書き方どおり、要素の箱で測っています。
  行間が大きいサイトだと、表の数字は見た目より小さく出ます。必要なら次の要望で言ってください。
- 見出しまわり以外の「要素どうしの間隔」（カードの中の余白など）はまだ測っていません。
